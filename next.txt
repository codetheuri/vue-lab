======================================================================
TASK: Implement Interactive Column Sorting in DataTable
======================================================================

Objective:
Right now our tables in Employees and Products display data, search, filter,
and paginate, but users cannot sort rows by clicking column headers.
Upgrade the table system to support interactive column sorting.

Requirements:

1. Sortable vs. Non-Sortable Columns:
   - Update the column configurations in both Employees.vue and Products.vue
     so we can define which columns are sortable.
   - Data columns (like Name, Department, Role, Join Date, SKU, Price, Stock)
     should be sortable.
   - The "Actions" column must NOT be sortable.

2. Interactive Table Headers & Visual Indicators (DataTable.vue):
   - Sortable column headers should look clickable (pointer cursor).
   - Display a Bootstrap Icon next to sortable header labels to indicate state:
     * Unsorted / Neutral state
     * Sorted Ascending (A -> Z, Lowest -> Highest)
     * Sorted Descending (Z -> A, Highest -> Lowest)
   - Clicking a sortable header should cycle through:
     Ascending -> Descending -> Unsorted (or toggle cleanly).

3. Data Type Handling:
   - Text columns (e.g., Name, Department, Category) must sort alphabetically
     (case-insensitive).
   - Numeric columns (e.g., Price, Stock Level) must sort numerically
     (e.g., 5 comes before 14, which comes before 100).

4. Pipeline Compatibility:
   - Sorting must work seamlessly alongside our existing Search, Category/Department
     Filters, and Pagination across ALL pages of data.
