======================================================================
TASK: Build a Global Toast Notification System (BaseToast + useToast)
======================================================================

Objective:
Right now, when a user adds, updates, or deletes an Employee or Product,
the action happens silently without any visual confirmation.
Build a reusable, global Toast Notification system using Vue 3 Composables
and Teleport.

Structure to Create:
src/
├── composables/
│   └── useToast.js
└── components/
    └── base/
        └── BaseToast.vue

Requirements:

1. Shared Toast State Composable (`src/composables/useToast.js`):
   - Maintain a reactive list of active toast notifications.
   - Each toast should have a unique `id`, `message`, and `type` (or variant:
     e.g., 'success', 'danger', 'info').
   - Provide helper functions to trigger toasts easily from any page:
     * `showSuccess(message)`
     * `showDanger(message)`
     * `showInfo(message)`
   - Provide a function to manually dismiss/remove a toast by its `id`.
   - Auto-dismiss: Each toast must automatically disappear after ~3.5 seconds.

2. Toast UI Component (`src/components/base/BaseToast.vue`):
   - Use Vue's `<Teleport to="body">` so toasts always float above all content
     and modals without z-index clipping.
   - Position the toast container fixed in the bottom-right (or top-right) corner
     of the screen.
   - Style each toast cleanly using Bootstrap 5 classes and Bootstrap Icons
     (e.g., green check icon for success, red trash/alert icon for danger).
   - Include a close (`X`) button on each toast so the user can dismiss it early.

3. Global Mounting & Page Integration:
   - Mount `<BaseToast />` once inside `App.vue` (or `DashboardLayout.vue`) so
     it works globally across all routes.
   - Trigger appropriate toast notifications in both `Employees.vue` and
     `Products.vue` when:
     * A new record is added (Success toast)
     * An existing record is updated (Success/Info toast)
     * A record is deleted (Danger/Warning toast)
