2. Convert useEmployees and useProducts into Pinia Stores
Now that Pinia is set up, let's move our employee and product state from composables into Pinia stores.
- Create `src/stores/employeeStore.js` (`useEmployeeStore`) and `src/stores/productStore.js` (`useProductStore`) using `defineStore`.
- Move all state, `localStorage` sync, computed stats, and CRUD actions (`add`, `update`, `delete`, `reset`) into these two stores.
- Update `Dashboard.vue`, `Employees.vue`, and `Products.vue` to use `useEmployeeStore()` and `useProductStore()`.
- Important: Use `storeToRefs()` from `'pinia'` when destructuring reactive state and computed properties (like `const { employees, totalEmployees } = storeToRefs(employeeStore)`), while destructuring action functions directly from the store.

3. Create an Activity Log Store (src/stores/activityStore.js) and show it on Dashboard.vue
Let's practice having Pinia stores work together to track user actions.
- Create `src/stores/activityStore.js` (`useActivityStore`) that stores a `logs` array in `localStorage` (`'app_activity_logs'`).
- Add a `logAction(action, details, variant = 'info')` method that unshifts a new log item (`{ id: Date.now(), userName, userRole, action, details, variant, time: new Date().toLocaleTimeString() }`) to the top of `logs` (keep the most recent 15 logs) and a `clearLogs()` method.
- Call `activityStore.logAction(...)` inside `employeeStore` and `productStore` whenever an item is added, updated, deleted, or reset (recording which user from `useAuthStore()` performed the action).
- On `Dashboard.vue`, add a "Recent Activity Log" card next to or below Recent Employees that lists these actions with a `<BaseBadge>` and timestamp, plus a "Clear Log" button (visible only to Admins).

4. Add a "My Profile" Modal in DashboardLayout.vue
- In `src/layouts/DashboardLayout.vue`, make clicking the user's name or avatar in the topbar open a `BaseModal` ("My Profile").
- Inside the modal, let the user edit their display `name` (using `BaseInput`) and switch their `role` between `Admin` and `Viewer` (using `BaseSelect`) for easy permission testing.
- Add an `updateProfile({ name, role })` action in `authStore.js` that updates `user.value`, saves to `localStorage`, and triggers a success toast.

5. Add Row Selection Checkboxes and Bulk Delete in DataTable.vue
- In `src/components/table/DataTable.vue`, add `selectable` (Boolean, default `false`) and `selectedIds` (Array, default `() => []`) props, and emit `update:selectedIds`.
- When `selectable` is true, display a checkbox column on the left:
  - The header checkbox selects or deselects all rows currently shown on the page.
  - Each row checkbox adds or removes `row.id` in `selectedIds`.
- In `Employees.vue` and `Products.vue`, enable `:selectable="authStore.isAdmin"` and `v-model:selectedIds="selectedIds"`. When 1 or more rows are checked, show a `"Delete Selected (X)"` danger button that deletes all selected records and clears `selectedIds`.
